# Protocol-Article

This repository contains the numerical data used to generate the figures in the manuscript submitted to the *Journal of Earthquake Engineering*.

## Manuscript

**Title:** Development of a Unified Nonsymmetrical Loading Protocol for Beam-to-column Connections in Deteriorating Steel Moment Resisting Frames

## Repository contents

- `data/`: Excel files containing the numerical data used to generate the manuscript figures.

## Available files

- `data/Figure_01_Data.xlsx`: Numerical data used to generate Figure 1. The file includes the AISC loading protocol and SAC near-fault loading protocol data.

## File organization

Each Excel file is named according to the corresponding figure number in the manuscript.

For figures containing multiple subfigures or datasets, the Excel file may include separate sheets or separated data blocks.
